# MuJoCo 最小仿真模板 · 怎么记

**核心结论**：模板骨架必须能手写；里面的细节参数、XML 可以查文档复制，不用死记硬背。

这段代码是 MuJoCo 最标准、最小可运行的仿真模板，也是后续项目（单摆、机械臂、RL 环境）的基础原型。

把代码拆成 3 部分分开看待。

---

## 1. 必须能手写出来的部分（骨架，背下来）

仿真固定框架，不管做什么机器人仿真，结构几乎不变：

```python
import mujoco
import mujoco.viewer

# 1. 加载模型（xml 字符串 / 文件）
model = mujoco.MjModel.from_xml_string(XML)
data = mujoco.MjData(model)
mujoco.mj_forward(model, data)

# 2. 被动查看器仿真循环
with mujoco.viewer.launch_passive(model, data) as viewer:
    while viewer.is_running():
        mujoco.mj_step(model, data)
        viewer.sync()
```

| 名字 | 作用 |
|------|------|
| `MjModel` | 静态模型（从 XML 编译出来，一般不再改） |
| `MjData` | 动态状态（位置、速度、时间，每一步都会变） |
| `mj_forward` | 根据当前 `qpos` 算出 `xpos` 等派生量（第一步仿真前要读高度时需要） |
| `mj_step(model, data)` | 推进仿真一步 |
| `viewer.sync()` | 刷新画面 |

**为什么要手写**：后面写 PD 控制器、IK、Gymnasium 环境，会反复写这套循环。如果每次都靠 AI 生成，调试会非常慢。面试、写项目时也需要快速搭起最小 demo。

## 2. 看懂逻辑即可，不用死记硬背

### 读物体高度

```python
block_id = model.body("block").id
height = data.xpos[block_id, 2]
```

- `data.xpos`：世界坐标系下刚体位置
- 索引：`0=x`，`1=y`，`2=z`（高度）
- 必须带上 **body id**，不能写成 `data.xpos[:, 2]`（那是所有刚体的 z）

会查即可：`qpos`、`qvel`、`xpos`、`xquat` 这些常用成员，知道去哪里读机器人状态。

不用背属性名字，但要知道概念：**某个物体的高度在 `data.xpos[body_id, 2]`**。

### 按仿真时间打印

```python
if data.time >= next_print_t:
    print(...)
    next_print_t += print_dt
```

理解：这里用的是仿真时间 `data.time`，不是系统时钟 `time.time()`。RL 做日志输出经常写类似逻辑。

### 真实时间休眠限速

```python
leftover = model.opt.timestep - (time.time() - step_start)
if leftover > 0:
    time.sleep(leftover)
```

- **理解作用**：限制渲染速度，让肉眼能看清仿真，不疯狂跑飞。
- **训练强化学习时直接删掉这一段**：训练不需要休眠，应全速跑。

不用一字不差默写，但要知道它是干什么的，以及训练 RL 时要删掉。

## 3. XML / MJCF：不要死记硬背，但要能手改、手写简易版

示例里的关键结构：`<worldbody>` → `<body>` → `<freejoint/>` + `<geom ...>`

- 简单场景（地面、方块、单摆）：要求能手写简易 XML
- 复杂材质、`texture`、`light` 这些美化标签：可以复制模板，不用背诵

必须掌握的 XML 基础（能手写）：

```xml
<mujoco>
  <worldbody>
    <geom type="plane"/>
    <body pos="0 0 1">
      <freejoint/>
      <geom type="box" size="0.05 0.05 0.05"/>
    </body>
  </worldbody>
</mujoco>
```

要懂：

- `<body>`：父子层级坐标系
- `freejoint`：自由 6 自由度关节；`hinge`：旋转关节
- `geom`：基础几何体，`box` / `sphere` / `capsule`

不要追求记住 `texture`、`material` 这些渲染美化标签，做项目复制粘贴即可。
